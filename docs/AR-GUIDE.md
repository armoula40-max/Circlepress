## 2. التثبيت (5 دقائق)

1. من لوحة ووردبريس: **المظهر ← قوالب ← أضف جديد ← رفع قالب** ← ارفع `circlepress.zip`.
2. فعّل القالب.
3. **المظهر ← تخصيص ← 🌐 Site Niche** ← اختر النيش → يتغير الستايل + الهوم + الـ Schema تلقائياً.
4. أنشئ صفحتين: **Home** (قالب `CirclePress Home — ...`) و **Blog**، ثم **إعدادات ← قراءة** ← صفحة رئيسية ثابتة.

> 💡 تقدر تخصص **صفحة واحدة بنيش مختلف** عن باقي الموقع (من صندوق Page Options أو قالب `CirclePress Home — X`).

## 3. تخصيص الصفحة الرئيسية

من **تخصيص ← Homepage**:
- عنوان وصورة الـ Hero.
- إظهار/إخفاء كل قسم: Hero، التصنيفات، المميزة، الرائجة، الأحدث، النشرة، FAQ.
- **Featured tag slug**: أي مقال تعطيه هذا الـ Tag يظهر في الـ Hero والمميزة (افتراضياً `featured`).

## 4. المقالات: كيف تظهر البطاقات والـ Schema؟

افتح أي مقال ← صندوق **CirclePress: Niche Details** ← املأ المجموعة التي تحتاجها فقط:

- **🍲 Recipe**: المكونات (سطر لكل مكوّن) + الخطوات (سطر لكل خطوة) + الأوقات + السعرات ← تظهر بطاقة الوصفة + `Recipe Schema` (مؤهل للـ Rich Results).
- **🛠️ How-To**: الأدوات + المواد + الخطوات + الوقت/الصعوبة/التكلفة ← بطاقة + `HowTo Schema`.
- **🛋️ Product**: الاسم + السعر + العملة + رابط الأفلييت + Pros/Cons ← بطاقة منتج + `Product` + `Review Schema`.
- **❓ FAQ**: سطر لكل سؤال بصيغة `السؤال | الجواب` ← أكورديون ظاهر + `FAQPage Schema`.
- **General**: تقييم بالنجوم، فيديو، إخفاء الإعلانات، Sponsored.

**شورتكودات** (تقرأ نفس البيانات تلقائياً):
`[recipe_card]` `[howto]` `[product_box]` `[pros_cons]` `[star_rating]` `[faq]` `[cta_button text=".." url=".."]` `[compare cols=".." rows=".."]` `[disclosure]` `[circlepress_ad slot="sidebar"]` `[cookie_settings]`

## 5. الإعلانات: AdSense / Ezoic / Mediavine

من **تخصيص ← 💰 Ads**: الصق الأكواد في الـ Slots الستة:

| Slot | المكان |
|---|---|
| header | أسفل القائمة |
| below_title | أسفل عنوان المقال |
| in_content | داخل المقال تلقائياً (تتحكم بعد أي فقرات: `2,5,8`) |
| sidebar | الشريط الجانبي |
| footer | فوق الفوتر |
| sticky_footer | شريط سفلي ثابت للموبايل (مع زر إغلاق) |

- **AdSense**: الصق كود `<ins class="adsbygoogle">` مباشرة.
- **Ezoic**: الصق الـ Placeholder divs في نفس الخانات (الثيم يحافظ على `data-ezoic` attributes).
- **Mediavine**: يعمل تلقائياً (Grow + بطاقة الوصفة متوافقة)، والخانات تنفع كمواضع إضافية.
- فعّل **Lazy-load** لتحسين Core Web Vitals.
- لإخفاء الإعلانات عن مقال معين: علّم **Hide ads** في صندوق المقال.

> ⚠️ ملف `ads.txt`: ارفعه في جذر الموقع (public_html) — الثيم لا يحتاج أي تعديل له.

## 6. الأفلييت

- **تخصيص ← 🤝 Affiliate**: نص الإفصاح التلقائي + `rel="nofollow sponsored"` للأزرار.
- أي مقال فيه منتج/رابط أفلييت يظهر فيه صندوق الإفصاح تلقائياً (مطلوب من FTC وأمازون).
- استعمل `[product_box]` و `[compare]` و `[pros_cons]` لرفع التحويل.

## 7. الـ SEO (جاهز للمراتب الأولى)

- ✅ عنوان واحد H1، بنية عناوين سليمة، HTML دلالي.
- ✅ Meta description تلقائي (أو مخصص لكل مقال) + Canonical + Robots.
- ✅ Open Graph + Twitter Cards.
- ✅ Breadcrumbs ظاهرة + `BreadcrumbList Schema`.
- ✅ جدول محتويات تلقائي من H2/H3 + وقت القراءة + شريط التقدم.
- ✅ Schema لكل نيش (جدول أعلاه) + `Organization/WebSite/SearchAction`.
- ✅ **يتعرف تلقائياً على RankMath/Yoast** ويوقف أجزاءه المكررة — بدون إعداد.
- ✅ سرعة: بدون jQuery، ملف JS واحد ~4KB، خطوط النظام افتراضياً، Lazy للإعلانات والفيديو.

## 8. الأداء للاستضافات الصغيرة

من **تخصيص ← ⚡ Performance**: إيقاف الإيموجي، oEmbed، jQuery Migrate، إبطاء Heartbeat، Preload للصورة البارزة. الثيم يعمل بسلاسة على استضافة مشتركة ضعيفة.

## 9. النشرة البريدية

**تخصيص ← Newsletter**: الصق رابط فورم Mailchimp / ConvertKit / Brevo ← يظهر صندوق اشتراك أنيق في الهوم وصفحات الـ Landing.

## 10. 🍪 بانر الكوكيز GDPR (جديد في 1.1.0)

من **تخصيص ← 🍪 Privacy & Consent**:

| الإعداد | الشرح |
|---|---|
| Mode = **Strict** | يمنع الإعلانات وفيديوهات YouTube/Vimeo حتى يوافق الزائر (مطلوب في أوروبا) |
| Mode = **Inform** | البانر يظهر فقط بدون منع أي شيء |
| Banner style | شريط سفلي كامل أو بطاقة عائمة في الزاوية |
| Reject button | زر الرفض (إلزامي حسب GDPR — اتركه مفعّلاً) |
| Consent Mode v2 | يرسل إشارات الموافقة لجوجل (AdSense/Analytics) تلقائياً ✅ |

- الموافقة تُحفظ **180 يوم** (كوكي + localStorage).
- بعد الاختيار تظهر أيقونة 🍪 أسفل اليسار لتغيير الإعدادات في أي وقت.
- ضع `[cookie_settings]` في صفحة سياسة الخصوصية لرابط "إعدادات الكوكيز".
- الفيديوهات الممنوعة تتحول لصورة جميلة مع زر تشغيل (Click-to-load) — تحميل أسرع + متوافق.

> ⚠️ مهم: أنشئ صفحة **Privacy Policy** من **إعدادات ← الخصوصية** في ووردبريس واذكر فيها: AdSense، Analytics، الأفلييت، ومدة الكوكيز.

## 13. ✨ إعادة التصميم الاحترافية (جديد 2.0.0)

أُعيد تصميم الثيم بالكامل بمستوى مدونات الطعام العالمية (مثل Veena Azmanov و Askinz):

- **أيقونات SVG** بدل الإيموجي في كل الواجهة: الهيدر، المشاركة، السوشيال، الميتا، شريط الإجراءات.
- **هيدر احترافي**: شريط علوي بأيقونات السوشيال + قائمة أحرف كبيرة بخط سفلي + ظل عند التمرير.
- **قائمة موبايل منزلقة (Drawer)** من الجانب مع بحث وسوشيال وقوائم فرعية أكورديون + إغلاق بزر Esc.
- **بحث بملء الشاشة** بخط كبير أنيق.
- **بطاقات بمستوى Pro**: زر Save الحمراء على الصور (مثل Mediavine)، نجوم التقييم، عنوان serif، وصف بسطرين.
- **بطاقة وصفة WPRM-style**: صورة + أزرار Save/Print/Pin + شريط معلومات بأيقونات + عمودين (مكونات/خطوات) + ملاحظات.
- **عناوين أقسام تحريرية**: Kicker صغير + عنوان serif كبير + "View all ←".
- **موبايل أولاً**: شريط الإجراءات يتمرر أفقياً، كل الشبكات والجداول والوصفات تتكدس بسلاسة حتى 360px.

> لا حاجة لأي إعداد — التصميم الجديد يعمل تلقائياً مع كل النيشات والتخطيطات.

## 15. 🔧 إصلاح الأزرار الميتة (2.0.2)

أزرار الوضع الليلي وحجم الخط (A+/A-) والموافقة (Accept/Reject/Customize) كانت لا تعمل لسبب تقني: عناصر الفوتر كانت تُطبع **بعد** تنفيذ السكربتات فلا يجدها الكود. الإصلاح: طباعة العناصر قبل السكربتات + انتظار جاهزية DOM + تكبير شامل للصفحة بزرّي الخط. صفحة الديمو أصبحت تفاعلية أيضاً (جرّب الأزرار فيها مباشرة).
