# Circlepress WordPress Theme

قالب ووردبريس تحريري بطابع وصفات الطعام، مستوحى من الاتجاه البصري العام لمواقع الوصفات الحديثة مثل askinz.com دون نسخ المحتوى أو الهوية.

## التثبيت

1. ارفع مجلد `Circlepress` إلى `wp-content/themes/`.
2. فعّل القالب من **المظهر → القوالب**.
3. أنشئ قائمة ووردبريس وعيّنها إلى **Primary Menu**.
4. عيّن صفحة رئيسية ثابتة؛ يستخدم القالب `front-page.php` تلقائيًا.
5. أضف الصور البارزة للمقالات لتحصل على بطاقات مخصصة. يوجد بديل بصور خارجية عند غياب الصورة.

## ما تم تضمينه

- تصميم متجاوب للجوال والسطح المكتب.
- ترويسة تحريرية مع قائمة قابلة للطي والبحث.
- صفحة رئيسية بواجهة Hero، أحدث المقالات، تصنيفات شائعة، ونموذج نشرة.
- قوالب للمقال المفرد، الصفحات، الأرشيف، التصنيفات، والبحث.
- دعم الصور البارزة، القوائم، عنوان الموقع، الشعار المخصص، وHTML5.
- بنية RTL أولية عند استخدام لغة عربية في ووردبريس.

## ملاحظة الصور

الصورة الافتراضية الخارجية مجرد fallback بصري. يفضّل استخدام صورك المرخصة ورفعها إلى مكتبة الوسائط في ووردبريس.
